# Prize2Pride — Japanese for Tunisian Learners

An independent, public, mobile-first Japanese learning starter for Tunisian learners. It uses Japanese dialogue-first situations, Tunisian Arabic guidance, device-local completion marks and reflections, browser speech replay, and an answer-free reading detective prompt.

The project is a fresh Prize2Pride product, inspired by the interaction principles of the Brazilian Portuguese platform without copying its lesson content. It contains no account requirement, tracking scripts, credentials, or automatic publication flow.

## Run locally

Open `index.html` in a modern browser. Run `npm test` to validate level coverage, dialogue structure, and clue activity data.

## Release boundaries

Human review is required for curriculum accuracy, Japanese script progression, accessibility, and any future server-side feature. Local progress uses browser storage only.
